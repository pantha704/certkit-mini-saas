# CertKit

**Browser-local certificate & key toolkit — your private key never leaves your browser.**

Static site (Astro) + a single vendored crypto/ASN.1 library (node-forge 1.4.0). No server,
no uploads, no accounts, no personal tracking; one cookie-less Cloudflare Web Analytics beacon
counts visits anonymously. RSA-first v1; EC/Ed25519 is on the roadmap.

Live: <https://localcertkit.pages.dev>

## Tools

| Page | What it does |
|---|---|
| `/pfx-to-pem/` | PFX/P12 → private key + certificate chain (PEM), with key-match badge |
| `/pem-to-pfx/` | PEM key + chain → PKCS#12, refuses key/cert mismatch, documents writer limits |
| `/certificate-decoder/` | X.509 decode (PEM/base64-DER): subject, issuer, SANs, validity, serial, sig alg, fingerprints, raw ASN.1 JSON |
| `/csr-decoder/` | PKCS#10 CSR decode + signature verification, requested SANs/extensions |
| `/key-cert-match/` | RSA modulus comparison + real SHA-256 sign/verify round-trip |
| `/chain-order/` | Orders certs leaf → intermediate → root, verifies issuer links, reports missing issuers |
| `/der-jwk-inspector/` | DER certificate inspection + JWK / JWK-set parsing (no verification claims) |

Plus `/privacy/`, `/about/`, `/contact/`, `/roadmap/` and a styled 404.

## Repo layout

```
lib/certkit.js            # the whole client library (UMD): parse/decode/order/match/inspect/write
vendor/forge.min.js       # node-forge 1.4.0, vendored (pinned; 1.3.x does NOT read AES PKCS#12)
site/                     # Astro static site (see below)
  src/pages/              # one file per page; src/layouts/ToolPage.astro is the tool shell
  public/js/boot.js       # lazy engine loader: forge + tools load on first interaction
  public/js/samples.js    # "Load sample" action shared by every tool
  public/js/ui.js         # shared browser UI helpers (dropzones, copy/download, errors)
  public/js/tools/*.js    # per-tool client scripts
  public/robots.txt, og.png, favicon.svg, favicon.ico
  public/samples/         # built-in test key, cert, chain, CSR, JWK (public, throwaway)
  assets/og.svg           # source of public/og.png (rendered in Chromium at 1200x630)
scripts/sync-site-lib.mjs # copies lib+forge into site/public before dev/build (single source)
scripts/make-fixtures.sh  # regenerates all throwaway test fixtures with OpenSSL 3.x
scripts/make-jwk-fixtures.mjs
fixtures/                 # throwaway self-signed keys/certs/CSRs/P12s + OpenSSL ground truth
tests/                    # evidence harnesses (see Testing)
EVIDENCE.md               # Gate-0 spike evidence (browser PKCS#12 feasibility)
```

`site/public/vendor/` and `site/public/lib/` are generated by the sync script (gitignored) —
`lib/certkit.js` and `vendor/forge.min.js` are the only copies that exist in git.

## Development

```bash
bun install                     # root deps: node-forge, playwright-core
cd site && bun install          # site deps: astro, @astrojs/sitemap

bun run site:dev                # dev server (syncs lib → site/public first)
bun run site:build              # static build → site/dist
bun run site:preview            # preview the built site
bun run site:check              # astro check (types)
```

`CHROME_PATH` overrides the Chromium binary used by the Playwright tests
(default: `~/.cache/ms-playwright/chromium-1243/chrome-linux64/chrome`).

## Testing (evidence, not vibes)

```bash
bun run test          # Gate-0 node smoke + real-browser spike (PKCS#12)
bun run test:lib      # Gate-1 library checks in Node (19 checks: decode/CSR/chain/JWK/write)
bun run site:build    # the browser + axe harnesses drive the BUILT site
bun run test:mvp      # Playwright harness: every tool, happy path + error path (tests/out/mvp-results.json)
bun run test:axe      # accessproof engine, WCAG 2.2 A/AA, every page (tests/out/axe-results.json)
bun run fixtures      # regenerate fixtures (needs OpenSSL 3.x)
```

Current status: `test:lib` 19/19, `test:mvp` 18/18, `test:axe` 13/13 pages with **0 axe
violations**. Evidence files live in `tests/out/`.

Weight: the homepage ships under 1 KB of JS (gzip, motion only). Tool pages ship about 3.4 KB
up front (boot + samples); node-forge (~73 KB gzip) loads on first interaction, so a tool page is
~91 KB gzip even once the engine is running, under the 100 KB DoD budget. Scroll is native: Lenis
and GSAP were removed in v1.1 (DoD §2 bans scroll-jacking, and both were pure weight here).

## Deploy

Static output, hosted on Cloudflare Pages:

```bash
cd site && bun run build
wrangler pages deploy site/dist --project-name localcertkit --branch main
```

`CLOUDFLARE_API_TOKEN` must be in the environment (scoped Pages:Edit token).

## Privacy model

Files are read with the browser File API and processed by JavaScript served from this domain.
No request in any tool flow carries a file, key or password. No cookies, no localStorage. The one
third-party request on the site is the cookie-less Cloudflare Web Analytics beacon, which supplies
anonymous aggregate visit counts (page, referrer, country, browser family) and never sees your
files. The same code is exercised by the Node and browser tests.

## Honest limitations (v1)

1. **RSA only.** EC/Ed25519 certificates, CSRs and PKCS#12 files fail with a friendly
   `EC_UNSUPPORTED` message and a roadmap link. (JWK inspection is JSON-only, so EC JWKs are fine.)
2. **PEM → PFX writer limits.** node-forge's writer produces an **HMAC-SHA-1 MAC** and stores
   certificate bags unencrypted (private key bag is AES-256-CBC). OpenSSL and Windows read it;
   strict platforms may prefer an OpenSSL-built PFX. The tool page states this before use.
3. **Chain order is a consistency check**, not trust validation (no revocation, hostname or
   policy checks).
4. **JWK inspector performs no verification** — parse-only, and it flags private key material.

> The `fixtures/` directory contains **throwaway self-signed test keys generated by the scripts** —
> safe to commit, never use for anything real.
